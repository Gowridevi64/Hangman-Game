## 1. Hangman Game

### Description
Hangman is a terminal-based word guessing game developed using Python. The player must guess the hidden word one letter at a time.

### Features
- Random secret word selection
- Six incorrect attempts
- Input validation
- Duplicate guess prevention
- ASCII hangman display
- Win and lose messages

### Technologies Used
- Python

### How to Run
```bash
python hangman.py
```
