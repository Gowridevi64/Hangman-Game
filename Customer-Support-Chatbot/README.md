# Customer Support Chatbot

## Project Overview
A rule-based customer support chatbot developed using Python. It identifies user intents using regular expressions and provides relevant responses to customer queries.

## Features
- Greeting and goodbye responses
- Business hours information
- Product price FAQs
- Payment, delivery, return and refund queries
- Multiple-intent matching
- Fallback responses for unknown questions
- Error handling and graceful exit commands
- Optional JSON-based FAQ dataset

## Technologies Used
- Python 3
- Regular Expressions (`re`)
- JSON
- VS Code
- Git and GitHub

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python chatbot.py
```
